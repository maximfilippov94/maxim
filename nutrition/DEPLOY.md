# Развёртывание NutriMenu на хостинге

## Требования
- **PHP 8.0 или новее** (рекомендуется 8.1–8.3). На PHP 7.x работать НЕ будет.
- Расширения PHP: `pdo_sqlite` (обязательно), `gd` (для иконок/загрузки фото).
- Apache (`.htaccess` + `mod_rewrite`) или nginx.

## Шаг 1. Переключить версию PHP
В панели хостинга выберите для домена **PHP 8.1+**.
На скриншоте ошибки было `PHP/7.1.33` — на нём приложение не запустится.

## Шаг 2. Куда указывает «корень сайта» (document root)
Точка входа — файл `public/index.php`, поэтому корень сайта должен смотреть
на папку **`public/`**. Есть два варианта:

**Вариант А (рекомендуется).** В панели хостинга укажите «Каталог сайта» =
`.../nutrition/public`. Тогда работает только `public/.htaccess`, а папки
`src/`, `bin/`, `data/`, `config.php` остаются вне веб-доступа (безопасно).

**Вариант Б (если корень поменять нельзя).** Залейте всё содержимое папки
`nutrition/` в корень домена. В комплекте есть корневой `.htaccess`, который
перенаправляет запросы в `public/` и закрывает служебные папки. Работает
«из коробки», но менее строго по безопасности, чем вариант А.

> **Важно про 500 «internal redirects» / петлю.** Не держите активными
> одновременно корневой `.htaccess` и `public/.htaccess`. Правильно —
> ОДИН из вариантов:
> - Вариант А: «Каталог сайта» = `.../public`, корневой `.htaccess` не нужен.
> - Вариант Б: проект в корне, корневой `.htaccess` перенаправляет в `public/`
>   (в нём есть защита от петли `RewriteRule ^public/ - [L]`).

> На странице 403 «отсутствует индексный документ» была именно эта проблема:
> корень домена смотрел на папку, где нет `index.php` (он лежит в `public/`).

## Шаг 3. Права на запись
Дайте права на запись (755/775, при необходимости 777) папкам:
- `data/` — здесь создаётся файл базы `app.sqlite`;
- `public/uploads/` — сюда сохраняются загруженные фото.

## Шаг 4. Установка (создать БД и данные)
**Если есть SSH:**
```bash
php bin/migrate.php      # схема БД
php bin/seed.php         # 67 ингредиентов + 34 блюда
php bin/seed_test.php    # тестовые аккаунты и демо-данные
# по желанию:
php bin/seed_admin.php   # 30 нутрициологов для наполнения админки
```

**Если SSH нет** — откройте в браузере:
```
https://ваш-домен/setup.php
```
Нажмите «Запустить установку». **После успешной установки удалите файл
`public/setup.php`** — он не должен оставаться на проде.

## Готово
- Главная: `https://ваш-домен/`
- Приложение: `/app/` (или кнопки на главной)
- Админка: `/app/#/admin`

## Частые ошибки
- **403 / нет индексного документа** → корень сайта не на `public/` (см. Шаг 2).
- **500 / белый экран** → скорее всего PHP 7.x. Переключите на 8.1+ (Шаг 1).
- **«database is locked» или не сохраняется** → нет прав на запись в `data/` (Шаг 3).
- **Не видно фото/иконок** → нет прав на `public/uploads/` или заблокирован доступ
  к статике; проверьте, что `public/.htaccess` на месте.

## Перенос на PostgreSQL (позже)
Весь SQL совместим с PostgreSQL. Достаточно поменять DSN в `src/Database.php`
и путь/тип БД в `config.php`; миграции применяются теми же `.sql`-файлами.
