# Как поставить EQUA на Android

Для Android платить Apple не нужно вовсе, и Mac тоже не нужен. Есть два
пути; первый проще и ничего не требует от вашей машины, кроме Node.

| Путь | Чем хорош | Чем плох |
|---|---|---|
| **А. Облачная сборка EAS** | собирает сервер Expo, аккаунт бесплатный, APK приходит ссылкой — его можно скинуть кому угодно | ждать 15–25 минут |
| **Б. Своя сборка** | собирается за минуты, без интернета | нужен Android Studio и ~8 ГБ места |

Уведомления с сервера на Android работают в обоих случаях — бесплатных
ограничений, как у Apple, здесь нет.

---

# Путь А. Облачная сборка (рекомендую)

## Шаг 1. Завести аккаунт Expo

```bash
npm install -g eas-cli
eas login
```

Регистрация на expo.dev бесплатная, карту не спрашивают. Бесплатного
лимита сборок хватает с запасом.

## Шаг 2. Забрать код

```bash
git clone https://github.com/maximfilippov94/maxim.git
cd maxim
git checkout claude/new-session-9cqu0s
cd nutrimenu-app
npm install
```

Если папка уже есть:

```bash
cd ~/путь/до/maxim
git fetch origin
git reset --hard origin/claude/new-session-9cqu0s
cd nutrimenu-app && npm install
```

## Шаг 3. Привязать проект

```bash
eas init
```

Команда допишет в `app.json` два поля — `owner` и
`extra.eas.projectId`. Это нормально, так и должно быть; после этого
имеет смысл закоммитить `app.json`, чтобы не привязывать заново.

## Шаг 4. Собрать APK

```bash
eas build --profile development --platform android
```

Ключ подписи EAS создаст сам — на вопрос «Generate a new Android
Keystore?» ответить **Yes**. Через 15–25 минут в терминале появится
ссылка; она же лежит в личном кабинете на expo.dev.

## Шаг 5. Поставить на телефон

Открыть ссылку в браузере **на самом телефоне** и скачать APK. Android
спросит разрешение на установку из этого источника — разрешить
(**Настройки → Приложения → Браузер → Установка неизвестных
приложений**). Ставится как обычное приложение, по кабелю ничего гнать
не нужно.

## Шаг 6. Как вести работу дальше

```bash
cd nutrimenu-app && npx expo start --dev-client
```

Открыть EQUA на телефоне, отсканировать QR из терминала — правки
экранов доезжают сразу, как в Expo Go, но со звонками и всем нативным.
Компьютер и телефон в одной сети Wi-Fi; если сеть не пускает, добавить
`--tunnel`.

## Сборка, чтобы просто показать

Профиль `development` ждёт подключения к компьютеру. Если APK нужен для
показа или для тестировщика — собрать так:

```bash
eas build --profile preview --platform android
```

Это самостоятельный APK: ставится и работает сам, без терминала.

# Путь Б. Своя сборка на своей машине

## Шаг 1. Поставить Android Studio

Скачать с developer.android.com/studio, при первом запуске согласиться
на предложенный набор (SDK, platform-tools, эмулятор). Затем прописать
переменные — для macOS и Linux в `~/.zshrc` или `~/.bashrc`:

```bash
export ANDROID_HOME="$HOME/Library/Android/sdk"   # Linux: $HOME/Android/Sdk
export PATH="$PATH:$ANDROID_HOME/platform-tools"
```

Нужен ещё **JDK 17** — Android Studio ставит свой, отдельно обычно не
требуется.

## Шаг 2. Включить разработку на телефоне

**Настройки → О телефоне → Номер сборки** — нажать семь раз, появится
раздел «Для разработчиков». В нём включить **Отладка по USB**.
Подключить кабелем и проверить:

```bash
adb devices
```

Телефон должен быть в списке со словом `device`. Если `unauthorized` —
на экране телефона подтвердить отпечаток компьютера.

## Шаг 3. Собрать и поставить

```bash
cd nutrimenu-app
npm install
npx expo run:android --device
```

Первая сборка — 10–20 минут (Gradle тянет зависимости), дальше минуты.
Приложение само встанет и откроется.

Дальше так же: `npx expo start --dev-client`.

## Если что-то не пошло

| Что видно | Почему | Что сделать |
|---|---|---|
| `eas build` просит projectId | не сделан `eas init` | шаг 3 пути А |
| APK скачался, но «Пакет не прошёл проверку» | файл скачан не до конца | скачать заново, не через мессенджер |
| «Приложение не установлено» | стоит другая сборка с тем же именем | удалить старое EQUA и поставить снова |
| QR сканируется, но ничего не грузится | разные сети | один Wi-Fi или `npx expo start --dev-client --tunnel` |
| Вход не проходит | нет связи с сервером | проверить, что `nutrimenu.ru` открывается в браузере телефона |
| `adb devices` пусто | не включена отладка по USB или кабель только для зарядки | шаг 2 пути Б, другой кабель |
| Gradle падает на `SDK location not found` | не прописан `ANDROID_HOME` | шаг 1 пути Б, перезапустить терминал |

## Публикация в Google Play

Разовый взнос 25 $, проверка обычно быстрее, чем у Apple. Сборка для
магазина (`.aab`):

```bash
eas build --profile production --platform android
```
