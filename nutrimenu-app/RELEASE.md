# Выпуск EQUA: сборки и магазины

Что уже сделано в проекте и что останется сделать руками. Порядок такой,
что до оплаты Apple можно пройти почти всё — на Android.

---

## 1. Что уже готово

| Что | Где | Состояние |
|---|---|---|
| Идентификатор iOS | `app.json` → `ios.bundleIdentifier` | `ru.equa.app` |
| Идентификатор Android | `app.json` → `android.package` | `ru.equa.app` |
| Значок 1024×1024 без прозрачности | `assets/icon.png` | годится для App Store |
| Значок Android | `assets/adaptive-icon.png` + фон | есть |
| Заставка | плагин `expo-splash-screen` | есть |
| Объяснения доступа (камера, микрофон, фото) | `app.json` → `ios.infoPlist` | на русском, по делу |
| Разрешения Android | `app.json` → `android.permissions` | камера, микрофон, уведомления |
| Экспортное заявление | `ios.config.usesNonExemptEncryption: false` | App Store Connect не будет спрашивать про шифрование при каждой загрузке |
| Профили сборки | `eas.json` | development, development-simulator, preview, production |
| Нативная часть звонков | `react-native-webrtc` + его плагин | в сборку попадёт, в Expo Go не работает |
| Клиент разработки | `expo-dev-client` | своя сборка подхватывает код с Mac, как Expo Go |

Версия приложения берётся из `app.json` → `version`, номер сборки
EAS считает сам (`appVersionSource: remote` и `autoIncrement` в профиле
production) — руками его трогать не нужно.

## 2. Чего не хватает и что добавится само

| Что | Как появится |
|---|---|
| `expo.owner` и `extra.eas.projectId` в `app.json` | допишет `eas init` при первом запуске под вашим аккаунтом |
| Подпись iOS | EAS создаст при первой сборке — нужен платный Apple Developer |
| Ключ подписи Android | EAS создаст сам при первой сборке, платить не нужно |

## 3. Android — можно прямо сейчас, бесплатно

```bash
npm install -g eas-cli
eas login                       # бесплатный аккаунт Expo
cd nutrimenu-app
eas init                        # привяжет проект, допишет projectId
eas build --profile development --platform android
```

Через 15–25 минут придёт ссылка на APK. Ставите на телефон, дальше:

```bash
npx expo start --dev-client
```

и сканируете QR — работает как Expo Go, но со звонками и всем нативным.

Собрать APK для показа без подхвата кода с Mac:

```bash
eas build --profile preview --platform android
```

## 4. iOS: что делать после оплаты 99 $

1. Оформить Apple Developer Program (apple.com/developer). Проверка
   занимает от нескольких часов до двух суток.
2. Собрать свою сборку для телефона:
   ```bash
   eas build --profile development --platform ios
   ```
   EAS спросит Apple ID, сам создаст сертификат и профиль, сам добавит
   телефон в список устройств.
3. Сборка для магазина:
   ```bash
   eas build --profile production --platform ios
   ```
4. Создать запись приложения в App Store Connect (имя, подкатегория,
   возрастной рейтинг) и отправить:
   ```bash
   eas submit --profile production --platform ios
   ```

### Что попросят в App Store Connect

- **Название и подзаголовок**, описание, ключевые слова — на русском.
- **Снимки экрана**: 6.7″ (iPhone 15/16 Pro Max) и 6.5″ — минимум по
  три. Снимаются с телефона или симулятора.
- **Ссылка на политику конфиденциальности** — обязательна. У вас она
  есть на сайте, в разделе правовых документов.
- **Опросник о данных** (App Privacy): приложение собирает имя, почту,
  данные о здоровье и питании; всё привязано к учётной записи.
  Отдельно отметить, что данные о здоровье не используются для рекламы.
- **Демо-учётка для проверяющего** — обязательна, иначе отклонят:
  вход в приложение закрыт. Завести отдельного клиента с заполненным
  меню и указать его почту и пароль в поле «Sign-in required».
- **Экспортное заявление** — уже закрыто флагом в `app.json`.

### Чего ждать при проверке

- **Данные о здоровье.** Раздел цикла и профиль здоровья Apple читает
  внимательно: в описании и в опроснике не должно быть обещаний
  диагностики или лечения. Формулировка «дневник наблюдений, не
  медицинское заключение» в приложении уже есть — она же годится для
  описания.
- **Платежи.** Услуги специалистов оплачиваются на сайте, в приложении
  оплаты нет — это нужно будет объяснить в примечании для проверяющего,
  иначе спросят про внутренние покупки Apple.

## 5. Google Play

Отдельный разовый взнос 25 $, проверка обычно быстрее.

```bash
eas build --profile production --platform android   # .aab для магазина
eas submit --profile production --platform android
```

Для автоматической отправки нужен сервисный ключ Google Play; без него
первый раз проще загрузить `.aab` руками в консоли.

---

## 6. Что меняется в повседневной работе

После установки `expo-dev-client` команда `npx expo start` открывает
проект в своей сборке, а не в Expo Go. Пока своей сборки нет, Expo Go
никуда не делся: нажмите **`s`** в терминале — переключится обратно.

Пересобирать нужно только когда добавляется нативный модуль. Правки
экранов, цветов и логики доезжают сразу, как раньше.
