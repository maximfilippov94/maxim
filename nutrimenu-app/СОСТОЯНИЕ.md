## Что это за проект

Мобильное приложение EQUA на Expo SDK 57. Второй продукт — веб на
PHP + SQLite, боевой на nutrimenu.ru; в репозитории его нет, он живёт
архивом в рабочем каталоге сессии.

Сквозная задача последних недель: **довести приложение до совпадения с
вебом** — по действиям, данным и виду. Веб здесь первоисточник. Своих
формулировок, своих наборов вариантов и своей структуры экранов быть не
должно: человек заполняет анкету в приложении, а правит её на сайте, и
расхождение читается как потерянный ответ.

## Как запускать

```bash
cd nutrimenu-app
npm install            # если node_modules нет
npx expo start --go    # флаг обязателен: в проекте стоит expo-dev-client
```

Проверки перед отправкой:

```bash
npx tsc --noEmit
npx eslint src app          # 87 замечаний — столько же было и до правок
npx expo export --platform ios
```

Состояние машины одной командой: `sh tools/doctor.sh`

## Чем проверять, а не угадывать

В `tools/` лежат замеры, написанные под конкретные промахи:

* `contrast.mjs` — контраст текста на заливке по обеим палитрам.
  Находит нечитаемые надписи. Сейчас 48 пар ниже порога 4.5, все в
  поле 3.9–4.4: это мелкие серые подписи, и токены там совпадают с
  вебом число в число. Трогать нельзя без решения владельца.
* `png-probe.mjs` — цвета и границы знака внутри PNG, без библиотек.
* `png-crop.mjs` — обрезка до квадрата и снятие прозрачности.
* `media-url.mjs` — картинки, чей адрес не прогнали через `mediaUrl`.
  Сервер отдаёт путь относительным, `Image` такой не грузит, и
  остаётся серая подложка — выглядит как «фото нет». Так пропал
  снимок профиля в шапке главной, а вместе с ним все аватары в
  чатах и списках; замер нашёл ещё три места, включая копию
  компонента `Face` в каталоге специалистов.
* `doctor.sh` — состояние проекта и машины.

Правило из `CLAUDE.md`, которое здесь нарушалось чаще всего: **замер
вместо предположения**. Три находки подряд нашёл человек глазами, а не
мои проверки, потому что они смотрели на код, а не на то, что видно на
экране. Если делаете правку вида — проверяйте её на устройстве.

## Открытые хвосты

1. **`/client/week` падает с 500 на боевом сервере.** Экран «Неделя»
   пустой. Причина пишется в терминал строкой `[api] GET /client/week
   → 500 …` — нужна она. Маршрут простой, падает что-то внутри
   `equaV84AiAccess`, `menuItems`, `menuPayload` или `equaV84MenuStale`;
   без текста ошибки выбирать из четырёх значит гадать.
2. **Контраст 3.9–4.4**, 48 пар. Решение владельца: чинить в обоих
   продуктах или оставить.
3. **Прозрачные углы значка.** App Store такой отклонит. Чинится
   `png-crop.mjs` за минуту, нужно только при публикации.
4. **Не проверить в Expo Go:** видеозвонки (нет нативной части,
   кнопка сама скрыта), уведомления с сервера, посторонний текст под
   нижней панелью (это Expo Go просвечивает через размытие — в своей
   сборке просвечивать нечему).

## Что предложено, но не начато

Замерено, владелец пока не выбрал:

* **«Потянуть и обновить» — на 3 экранах из 58.** Базовый жест не
  работает почти нигде; данные приходят с сервера и устаревают.
* **Ошибка загрузки — тупик.** 60 мест кладут ошибку в состояние,
  кнопка «Повторить» есть на одном экране.
* **Озвучка:** подписи у 30 нажимаемых из 257.

## Про сборку под iPhone

Mac для неё не нужен: EAS собирает в облаке своим Xcode. Упирается в
Apple Developer Program (99 $) — без него подпись под устройство не
выдаётся, и `.ipa` не встанет ни из облака, ни откуда ещё. Порядок
записан в `УСТАНОВКА-IPHONE.md`, Android — в `УСТАНОВКА-ANDROID.md`.
