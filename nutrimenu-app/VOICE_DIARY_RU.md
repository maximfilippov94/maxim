# Голосовой дневник EQUA AI — Expo SDK 57

На «Сегодня» добавлена закреплённая кнопка микрофона. Она открывает нативное окно, запрашивает микрофон и начинает запись. Шар реагирует на реальные PCM-данные. Остановка и лимит 24 секунды удерживают запись до нажатия отправки. Распознавание, справочник и сохранение используют существующий авторизованный API EQUA. Ключей облачного провайдера в приложении нет.

## Запуск в Expo Go

Из корня репозитория:

```bash
git switch codex/expo-voice-diary
git pull --ff-only origin codex/expo-voice-diary
cd nutrimenu-app
npm ci
npx expo start -c
```

Откройте QR-код в Expo Go с поддержкой SDK 57. Разрешите микрофон. Новая функция использует уже установленный `expo-audio`, без собственного нативного модуля и без WebView. Если Expo Go сообщает об отсутствии AudioStream, обновите Expo Go. Экспорт Metro не заменяет проверку микрофона на физическом телефоне.

По умолчанию используется `https://nutrimenu.ru`. Для другого сервера задайте только публичный адрес в `.env.local`:

```dotenv
EXPO_PUBLIC_API_BASE=https://ваш-домен.ru
```

Не помещайте API-ключи в переменные `EXPO_PUBLIC_*`.

## Сервер на SpaceWeb

На хостинге нужен полный комплект EQUA v279. Сначала сделайте согласованную резервную копию файлов и SQLite. Загрузите содержимое public_html поверх корня сайта, сохранив рабочие config/config.php, config/food-voice.php, config/ai.php, остальные приватные конфиги и storage. API-ключи менять не требуется.

Новая миграция 085_food_voice_preferences.sql хранит персональные подтверждённые сопоставления. Штатный загрузчик миграций применяет её при запуске ядра; миграция 084_food_voice.sql также необходима. Всего в полном комплекте 89 SQL-файлов. Пользовательская база не заменяется, LIVE-платежи остаются выключенными. На старом API голосовые уточнения скрыты до обновления сервера.

Ошибка «разобранные продукты не совпали с записью» означала отказ проверки результата AI после распознавания речи. v278 сравнивает эквивалентные числа и единицы (`сто граммов` / `100 г`), пунктуацию и пробелы. При несовпадении один раз автоматически повторяет разбор того же распознанного текста с требованием точных цитат. Повторно отправлять звук для этой внутренней проверки не нужно. Проверка не разрешает придумывать продукты и вес. Без исходной фразы с последнего скриншота конкретную причину того случая подтвердить нельзя.

## Поведение

- Краткий список: продукт, количество, калории; уточнение варианта раскрывается в строке.
- Дата берётся локально в момент открытия, без календаря.
- Завтрак, перекус после завтрака, обед, перекус после обеда, ужин — пять разных слотов. Если AI определил один приём, он применяется к неопределённым строкам. Разные явно названные приёмы сохраняются. Неизвестный приём уточняется для списка один раз.
- Количество можно менять в граммах или штуках при наличии массы штуки в справочнике. Неизвестная масса не выдумывается. Редактирование отменяется кнопкой назад.
- Запись и повторная отправка не требуют ручного набора текста. Клавиатура остаётся дополнительным способом ввода.
- При обрыве сети аудио и ключ запроса сохраняются внутри открытого окна. При закрытии запись удаляется. После распознавания временный PCM-файл удаляется. Уход в фон останавливает микрофон.
- Сохранение происходит только после подтверждения. КБЖУ рассчитывает сервер. «Записано» появляется после ответа сервера, затем обновляется «Сегодня».
- Функция доступна клиентам EQUA AI и клиентам реального специалиста; прав на платный AI-чат она не добавляет.

## Исправление загрузки аудио 16.10.2026

Expo SDK 57 по умолчанию использует Expo fetch. Старый multipart-дескриптор `{uri, name, type}` не поддерживается этим кодировщиком и вызывал исключение до HTTP-запроса. Голосовая загрузка теперь передаёт настоящий `expo-file-system File` и явно использует `expo/fetch`, сохраняя общий API-клиент, Bearer, таймаут, отмену и ключ повторной отправки. Остальные запросы используют прежний транспорт.

Проверка включает настоящий установленный `installFormDataPatch` и `convertFormDataAsync`: старый дескриптор воспроизводит ошибку, семисекундный PCM-файл сохраняет все 224000 байт, файл и метаданные получают multipart-заголовки. Проверен выбор транспорта в реальном API-клиенте и отсутствие ошибочного сообщения об интернете при локальной ошибке загрузки. Всего 59 проверок, включая новые уточнения списка. TypeScript и ESLint изменённых файлов проходят.

Для исправления multipart сервер менять не требуется. Для новых возможностей v279 обновите также хостинг. Остановите Metro клавишами Ctrl+C и выполните из корня локального репозитория:

```bash
git pull --ff-only origin codex/expo-voice-diary
cd nutrimenu-app
npx expo start -c
```

Повторно откройте приложение в Expo Go. Проверка на физическом телефоне остаётся обязательной перед выпуском.

## v279: подбор, голосовые уточнения и новая сфера

- Поиск сопоставляет название и бренд, понимает Тео/Теос/Teos, формы слов и характеристики продукта. Жирность, безлактозность, состав и приготовление проверяются отдельно. Близкий вариант предлагается явно и требует выбора; отсутствующая жирность не подменяется другой.
- Реальные кандидаты показываются в списке. Отсутствие продукта означает отсутствие точного совпадения в справочнике, а не ошибку распознавания речи.
- «Уточнить список голосом» принимает короткую поправку к существующему списку. «Уточнить этот продукт голосом» ограничивает поправку выбранной строкой. Неоднозначная команда не применяется наугад. Остальные продукты, ручные варианты, количество и приёмы сохраняются. Отмена возвращает прежний список.
- После подтверждённого сохранения сервер запоминает совместимый выбор этого клиента (до 500 сопоставлений). Выбор другого клиента и неподходящая характеристика не переиспользуются.
- Вместо орбит и контуров — цельная светлая сфера с мягкими лаймовыми переливами. Громкость влияет на движение; системное уменьшение движения учитывается.

Новые проверки: 59 нативных проверок, TypeScript, ESLint изменённых файлов и экспорт iOS/Android. Проверки PHP/API, PWA, offline и миграций находятся в отчёте полного комплекта v279. Реальное качество речи и плавность на телефоне нужно проверить с рабочим облаком в Expo Go: физические устройства здесь недоступны.

На Mac текущая копия проекта расположена в $HOME/EQUA-voice. Для каждого обновления остановите Metro и выполните:

```bash
cd "$HOME/EQUA-voice" &&
git pull --ff-only origin codex/expo-voice-diary &&
cd nutrimenu-app &&
npm ci &&
npx expo start -c
```
