# Page CRO — Conversion Rate Optimization Agent

Source: coreyhaines31/marketingskills · skills/cro

## When to Use
Activate when: низкая конверсия, брошенные корзины, слабый CTA, отказы на товарных страницах, оптимизация лендинга, A/B тест идеи, улучшение checkout.

## 7 Dimensions of Analysis

1. **Value Proposition Clarity** — Посетитель понимает оффер за 5 секунд?
2. **Headline Effectiveness** — Заголовок передаёт конкретную выгоду?
3. **CTA Strategy** — Видимость, копирайтинг, иерархия действий
4. **Visual Hierarchy** — Сканируемость, визуальные акценты на ключевых элементах
5. **Trust Signals** — Соц. доказательства, отзывы, гарантии, логотипы
6. **Objection Handling** — FAQ, гарантии, прозрачность
7. **Friction Points** — Поля форм, навигация, мобильный опыт, скорость загрузки

## E-Commerce CRO Checklist

### Product Page (PDP)
- [ ] Цена видна без скролла (above the fold на мобильном)
- [ ] Кнопка "В корзину" — контрастная, крупная, sticky на мобильном
- [ ] Фото товара высокого качества (несколько ракурсов, zoom)
- [ ] Социальное доказательство рядом с CTA (рейтинг, кол-во отзывов)
- [ ] Короткое описание выгод (не характеристики, а что даёт покупателю)
- [ ] Срочность/дефицит если реально актуально (осталось N шт.)
- [ ] Доставка и возврат — рядом с ценой, не в футере
- [ ] Блок "Похожие товары" для cross-sell

### Cart & Checkout
- [ ] Минимум полей — только необходимые
- [ ] Progress indicator (шаг 1 из 3)
- [ ] Итоговая сумма всегда видна
- [ ] Несколько способов оплаты
- [ ] Guest checkout (без обязательной регистрации)
- [ ] Trust badges рядом с кнопкой оплаты
- [ ] Autocomplete на полях адреса

### Homepage / Landing
- [ ] Hero: оффер + CTA выше fold
- [ ] Категории/товары с фото — не просто текстовые ссылки
- [ ] Социальное доказательство (отзывы, кол-во клиентов)
- [ ] Блок с УТП / преимуществами
- [ ] Вторичный CTA для тех кто не готов купить сейчас

## Quick Win Ideas для LUKA OUTDOOR
- Добавить счётчик просмотров или "купили X человек" на PDP
- Блок "Доставка бесплатно от N₽" в header
- Таймер ограниченного предложения (если есть акция)
- Фото живых людей с товаром (lifestyle), не только предметка
- Кнопка "Купить в 1 клик" / WhatsApp — уже есть ✅
- Блок гарантии/возврата рядом с ценой

## Метрики для отслеживания
- Add-to-cart rate (цель: > 5%)
- Cart-to-checkout rate (цель: > 60%)
- Checkout completion rate (цель: > 70%)
- Page bounce rate на PDP (цель: < 55%)

## A/B Test Ideas
1. CTA текст: "В корзину" vs "Купить сейчас"
2. Цена: показывать старую цену (зачёркнутую) vs без неё
3. Расположение отзывов: под CTA vs внизу страницы
4. Hero: фото товара vs lifestyle фото
